## Perspective

Technology should not end at feature implementation. Stable operation requires attention to **reliability, security, observability, recoverability, and measurable integrity**. A system becomes trustworthy only when those properties are considered together, tested under realistic conditions, and continuously evaluated throughout its lifecycle.

The portfolio therefore favors system-level reasoning over isolated demonstrations. It examines architecture, execution paths, trust boundaries, exposure surfaces, network behavior, automation workflows, and the evidence needed to distinguish an assumption from a verified result.

## Selected Work

### Syfx — Verifiable Autonomous Execution
Syfx is an autonomous strategy execution platform centered on verifiable procedures and accountable operations. It models strategy execution as a controlled workflow in which actions, logic, and results can be reviewed rather than accepted as opaque outcomes.

**Technology themes:** Blockchain · Execution Proof · Validation

### AEGIS — Network Security
AEGIS investigates network exposure and protection behavior through a security-oriented engineering workflow. The project emphasizes practical defenses, controlled analysis, and repeatable evaluation of network-facing systems.

**Technology themes:** Network Security · Exposure Analysis · WireGuard

### Fetcher — Media Processing Utility
Fetcher is a media download and processing utility designed to streamline remote assets, playlists, and network resources into controlled local workflows. The project focuses on reliability, automation, and maintainable media processing.

**Technology themes:** Automation · Media Handling · Data Processing

### Grabbit — API Key Intelligence
Grabbit explores the collection and analysis of API keys and public endpoints, using structured API-key intelligence to identify exposed or misconfigured resources and assess likely risk. It is intended as an analytical tool, not merely as a key-discovery utility.

**Technology themes:** API Security · Key Intelligence · Exposure Detection

### RelayDesk — Remote Operations Platform
RelayDesk provides remote support and system management capabilities for coordinated device operations. It combines session control, screen sharing, diagnostics, and remote management into a unified operational workflow.

**Technology themes:** Remote Access · Session Control · System Diagnostics

### NetRat — Network Intelligence
NetRat brings IP addresses, DNS information, network response characteristics, and host metadata into a network-infrastructure intelligence workflow. It supports structured examination of network state and asset context.

**Technology themes:** OSINT · DNS · Network Analysis

### LPEClient Research — Threat Intelligence & Malware Analysis
The LPEClient research note documents a Windows-focused study of process privilege escalation, LPE techniques, and browser-security context. The work examines post-exploitation visibility, Windows system behavior, ML-KEM-1024 findings, threat indicators, and attacker-detection context.

The research emphasizes evidence, suspicious process names, malformed behavior, and security-oriented observations rather than unsupported conclusions.

**Technology themes:** Windows Security · Reverse Engineering · ML-KEM-1024 · Threat Detection

## Engineering Principles

### Evidence Before Assumption
Technical decisions should begin with measurable data, reproducible observations, and evidence that can be tested or challenged.

### Testability Before Trust
Architecture, security controls, network behavior, recovery procedures, and system outputs should be built to admit verification and falsification.

### Resilience Before Convenience
Systems should remain visible and controllable under failure, degradation, uncertainty, and compromise—not merely under ideal operating conditions.

## Deployment

Because the portfolio is a static web experience, it can be hosted by any platform supporting HTML, CSS, and JavaScript. GitHub Pages is a natural fit for the repository.

```bash
# Clone the repository
git clone https://github.com/parkjin-hyok/portfolio.git
cd portfolio

# Preview locally
python3 -m http.server 8080
```

Then open `http://localhost:8080` in a browser.
